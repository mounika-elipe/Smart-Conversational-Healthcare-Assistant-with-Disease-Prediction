# Smart Conversational Healthcare Assistant

An AI-powered healthcare assistant that predicts diseases from **voice and optional image inputs**. Supports **multilingual interaction** and provides **real-time guidance**.

## Features
- Voice-based symptom input
- Disease prediction using ML models
- Optional image-based symptom analysis
- Conversational AI responses

## Tech Stack
- **Frontend:** React.js
- **Backend:** Flask / Express
- **Database:** MongoDB
- **AI/ML:** TensorFlow / PyTorch
- **UI:** Gradio / Streamlit

## Setup
```bash
git clone https://github.com/mounika-elipe/Smart-Conversational-Healthcare-Assistant-with-Disease-Prediction.git
cd Smart-Conversational-Healthcare-Assistant-with-Disease-Prediction
pip install -r requirements.txt
cd frontend
npm install
npm start
